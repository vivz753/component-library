# Matcha UI

This library contains components I've made for various projects. The goal is to organize them into one space for portfolio purposes and also for ease of frontend development.

It is inspired by 2 things that I love: tea and cats. It will be periodically updated with more components and customizations.

Enjoy!

<img src="/mimi.png" alt="vivian and mimi" width="200"/> - Vivian

### NOTE

Some components, i.e. LoadingOverlay won't show on the intial document page. It was designed to fit to cover an entire page with an overlay, so it is best viewed on the individual story.

All components were written in React, TailwindCSS, along with additional libraries like D3, react-spring, hamburger-react, react-icons, etc.
